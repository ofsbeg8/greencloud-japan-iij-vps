## 绿云的日本 IIJ 线路是什么水平

IIJ 是日本老牌运营商 Internet Initiative Japan 提供的国际 BGP 线路，走普通国际出口，和电信 CN2 那种有专门回国通道的线路是两回事。日常延迟大概 60-100ms，晚高峰（8-11 点）电信、联通有绕路风险，延迟可能升到 100-150ms。换来的是价格：CN2 线路通常贵 2-3 倍。

绿云成立于 2013 年，美国主机商，低价高配年付是它的招牌。东京 IIJ 机房用 EPYC Milan 或 Xeon E5v4 处理器、NVMe 或 SSD RAID-10 存储、10Gbps 端口，KVM 虚构，VirtFusion 面板，每款带 1 个 IPv4 和 /64 IPv6。从第三方评测的历史数据看，电信回程走 IIJ 直连时北京方向约 79ms，电信回程广州约 52-53ms，移动上海约 60ms，这个延迟对建站和中日互通业务完全够用。

一句话定位：IIJ 是 CN2 的性价比替代，高峰期可能有波动，但日常表现对得起价格。
